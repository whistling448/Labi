## Общее для всех заданий

Эти куски повторяются почти в каждом файле. Разберитесь с ними один раз.

### Начало файла

- `#include <...>` подключает стандартные библиотеки:
  - `stdio.h` — `printf`, `fopen`, `fgetc`;
  - `stdlib.h` — `malloc`, `free`, `strtol`, `strtod`, `rand`, `qsort`;
  - `string.h` — `strlen`, `strcmp`, `strcpy`;
  - `math.h` — `sqrt`, `pow`, `log`, `exp`, `fabs` (поэтому при сборке нужен `-lm`);
  - `errno.h` — `errno`, `ERANGE`;
  - `ctype.h` — `isspace`;
  - `limits.h` — `LONG_MAX`, `ULLONG_MAX`;
  - `stdarg.h` — переменное число аргументов (задание 6).
- `#define ИМЯ значение` — константа. До компиляции имя заменяется на значение. Это не переменная, поэтому требование «нет глобальных переменных» не нарушено.

### enum Status

```c
typedef enum { STATUS_OK, STATUS_NULL_POINTER, ... } Status;
```

Набор кодов результата: 0 — успех, остальные — разные ошибки. Каждая функция возвращает `Status`, а результат отдаёт через указатель-параметр. `main` разбирает статус через `switch` или `if`. Этого требует условие задания.

### Результат через указатель

```c
Status factorial(const long x, unsigned long long *result) {
    ...
    *result = value;     // результат — по адресу
    return STATUS_OK;    // статус — через return
}
factorial(5, &f);        // передаём адрес переменной f
```

### Проверки в начале каждой функции

```c
if (result == NULL) return STATUS_NULL_POINTER;   // указатель не пустой
if (eps <= 0.0)    return STATUS_INVALID_EPSILON; // параметр допустимый
```

Функция проверяет свои параметры сама, кто бы её ни вызывал.

### parse_long / parse_double / parse_int — строка → число

```c
if (*str == '\0' || isspace((unsigned char)*str)) → ошибка   // пустая строка или пробел в начале
errno = 0;
value = strtol(str, &end, 10);      // для double: strtod(str, &end)
if (*end != '\0')    → ошибка        // после числа остались символы ("12abc")
if (errno == ERANGE) → переполнение  // число не влезает в тип
```

- `end` после вызова указывает на место, где разбор остановился. Если вся строка — число, это `'\0'`.
- `errno` — стандартная переменная, в которую `strtol` пишет код ошибки. Перед вызовом её обнуляют.
- Для `double` ещё проверяется `isfinite(value)`: отсекаются `inf` и `nan`.
- `atoi`/`atof` не используются: они не сообщают об ошибках (`atoi("abc")` = 0).

### Проверка флага

```c
if ((flag[0] != '-' && flag[0] != '/') || flag[1] == '\0' || flag[2] != '\0') → ошибка
```

Первый символ `-` или `/`, затем ровно одна буква. Дальше выбор действия: `switch (flag[1])`.

### Сравнение вещественных чисел

`fabs(a - b) < eps` вместо `a == b`. Дробные числа хранятся неточно (0.1 + 0.2 ≠ 0.3), а условие требует eps как параметр функции.

## Задание 1 — task1.c

Запуск: `.\task1.exe <x> <флаг>`, например `.\task1.exe 15 -h`.

### find_multiples (-h)

```c
for (i = x; i <= MAX_MULTIPLE; i += x) { multiples[*count] = i; (*count)++; }
```

Шаг цикла равен x, поэтому перебираются только кратные: x, 2x, 3x… до 100. Результат кладётся в массив, количество — в `count`. При x ≤ 0 ошибка: при x = 0 цикл стал бы бесконечным. Если кратных нет (x > 100), `count = 0`, и `main` печатает «нет чисел».

### check_prime (-p)

```c
if (x < 2) → ни простое, ни составное (0 и 1)
for (i = 2; i <= x / i; i++)
    if (x % i == 0) → составное
иначе → простое
```

- Делители достаточно проверять до √x: если x = a·b и оба множителя больше √x, то a·b > x.
- `i <= x / i` — то же самое, что `i * i <= x`, но без риска переполнения.
- Отрицательные числа — ошибка.

### split_hex (-s)

```c
do { digits[count++] = alphabet[value % 16]; value /= 16; } while (value > 0);
затем разворот массива
```

Перевод в 16-ю систему делением с остатком. Остатки дают цифры от младшей к старшей, поэтому массив потом разворачивается. `alphabet = "0123456789ABCDEF"`: остаток 10 → `'A'`. Для отрицательного x модуль берётся как `0UL - (unsigned long)x`: это работает даже для минимального `long`, у которого `-x` не помещается в тип.

### power_table (-e)

```c
table[base-1][0] = base;
table[base-1][e-1] = table[base-1][e-2] * base;
```

Каждая степень — предыдущая, умноженная на основание. Индексы с `-1`, потому что массивы нумеруются с 0. Тип `long long`, потому что 10¹⁰ не влезает в `int`. x должен быть от 1 до 10.

### sum_to (-a)

Формула Гаусса x(x+1)/2. Из чисел x и x+1 одно чётное, его делят на 2 заранее. Перед умножением проверка `a > ULLONG_MAX / b` — переполнение.

### factorial (-f)

Умножение 2·3·…·x. Перед каждым умножением проверка `value > ULLONG_MAX / i`. 20! — максимум для `unsigned long long`, 21! даёт переполнение. 0! = 1.

### print_status

`switch` по статусу печатает текст ошибки. Это только вывод, без вычислений.

### main

1. `argc != 3` — ошибка.
2. `parse_long(argv[1], &x)` — число.
3. Проверка флага.
4. `switch (flag[1])`: в каждом `case` вызвать функцию, проверить статус, напечатать результат.

## Задание 2 — task2.c

Запуск: `.\task2.exe 0.0001`. Пять констант (e, π, ln 2, √2, γ), каждая тремя способами: предел, ряд, уравнение. Итого 15 функций.

### Типы

```c
typedef double (*Equation)(double x, double param);   // уравнение f(x) = 0
typedef Status (*Method)(double eps, double *result); // способ вычисления константы
```

Указатели на функции. Все 15 способов имеют вид `Method`, поэтому их можно сложить в массив.

### check_eps

eps должен быть в интервале (0, 1) и конечным.

### bisection — метод дихотомии

```c
fa = f(a, param);
if (fa * f(b, param) > 0) → STATUS_INVALID_INTERVAL   // знаки одинаковые
while (b - a > eps) {
    mid = (a + b) / 2;
    if (fa * f(mid) <= 0) b = mid;          // корень слева
    else { a = mid; fa = f(mid); }          // корень справа
}
*root = (a + b) / 2;
```

Если на концах отрезка функция имеет разные знаки, внутри есть корень. Делим отрезок пополам и оставляем половину, где знаки разные. Произведение двух чисел отрицательно ⇔ знаки разные. `MAX_BISECTION_STEPS` — страховка от зависания.

### equation_e / _pi / _ln2 / _sqrt2 / _gamma

Уравнения в виде f(x) = 0:

| Функция | f(x) | Уравнение |
|---|---|---|
| `equation_e` | `log(x) - 1` | ln x = 1 |
| `equation_pi` | `cos(x / 2)` | cos x = −1 |
| `equation_ln2` | `exp(x) - 2` | eˣ = 2 |
| `equation_sqrt2` | `x * x - 2` | x² = 2 |
| `equation_gamma` | `exp(-x) - param` | e⁻ˣ = L |

- `(void)param;` подавляет предупреждение о неиспользуемом параметре.
- Почему для π `cos(x/2)`: функция cos x + 1 касается нуля, но не меняет знак, а дихотомии нужна смена знака. cos x + 1 = 2cos²(x/2), поэтому корни те же, а cos(x/2) знак меняет.

### Шаблон «предел» — e_limit, ln2_limit

```c
n *= 2;  cur = формула(n);
if (fabs(cur - prev) < eps) → готово
prev = cur;
```

n удваивается, сравниваются соседние значения.
- e: (1 + 1/n)ⁿ;
- ln 2: n(2^(1/n) − 1).

Числа 1/2ᵏ хранятся в `double` точно.

### pi_limit

Формула (2ⁿn!)⁴/(n((2n)!)²) «в лоб» переполнилась бы. Значение обновляется умножением: `value *= 4n(n+1)/(2n+1)²`, начиная с 4 при n = 1. Сравнение делается, когда n — степень двойки.

### sqrt2_limit

Итерация xₙ₊₁ = xₙ − xₙ²/2 + 1, x₀ = −0.5, пока |xₙ₊₁ − xₙ| ≥ eps. Сходится к √2, так как в этой точке x² = 2.

### Шаблон «ряд» — e_series, pi_series, ln2_series

Складываем члены, пока член ≥ eps.
- e: `term /= n` — 1/n! получается из 1/(n−1)!, без вычисления факториала.
- π: 4·(1 − 1/3 + 1/5 − …).
- ln 2: 1 − 1/2 + 1/3 − ….

Для знакочередующихся рядов ошибка не больше первого отброшенного члена (признак Лейбница).

### sqrt2_product

Произведение 2^(1/4) · 2^(1/8) · …: показатель каждый раз делится на 2. Останавливаемся, когда множитель − 1 < eps.

### e_equation и другие ..._equation

Одна строка: `return bisection(equation_e, 0.0, 2.0, 3.0, eps, result);` — решить уравнение на отрезке, где корень точно есть.

### gamma_limit

Для m = 1, 2, … считает Σ C(m,k)(−1)ᵏ/k · ln(k!). Биномиальный коэффициент и ln(k!) накапливаются в цикле. Останавливается, когда соседние m дают разницу < eps. m ≤ 40, потому что дальше вычитание огромных чисел уничтожает точность. Тогда возвращается `STATUS_ITERATION_LIMIT`.

### gamma_series

−π²/6 + Σ(1/⌊√k⌋² − 1/k). Суммирование блоками: все k с одинаковым ⌊√k⌋ = n, то есть от n² до (n+1)² − 1. Ряд сходится очень медленно. Остановка, когда |блок|·n < eps, иначе лимит итераций.

### mertens_limit

Предел ln t · ∏(p−1)/p по простым p ≤ t.
1. `calloc` выделяет массив из 10 млн байт для решета Эратосфена, заполненный нулями.
2. Для каждого простого t (не вычеркнутого) домножаем произведение и вычёркиваем кратные, начиная с t².
3. В точках t = 2, 4, 8, … сравниваем значения.
4. В конце обязательно `free`.

### gamma_equation

Вычисляет L через `mertens_limit`, затем решает e⁻ˣ = L дихотомией, передавая L как `param`.

### main

```c
Method methods[5][3] = { {e_limit, e_series, e_equation}, ... };
for (i...) for (j...) status = methods[i][j](eps, &value);
```

Таблица функций 5 × 3, вызов в двойном цикле, `switch` по статусу. `STATUS_ITERATION_LIMIT` печатается с пометкой «точность не гарантируется».

## Задание 3 — task3.c

Запуск: `-q eps a b c`, `-m a b` или `-t eps a b c`.

### Типы

- `RootsType` — `enum`: `ROOTS_NONE`, `ROOTS_ONE`, `ROOTS_TWO`, `ROOTS_INFINITE`.
- `Equation` — `struct` с полями a, b, c, type, x1, x2: одно уравнение и его ответ. Доступ к полям: `eq.a`, а через указатель `p->a`.

### parse_numbers

Переводит сразу несколько строк в массив `double`. В `main` вызывается как `parse_numbers(argv + 2, 4, numbers)`: `argv + 2` — массив, начиная с третьего аргумента (пропускаем имя программы и флаг).

### solve_quadratic

- |a| < eps — линейное уравнение bx + c = 0:
  - b ≠ 0 → один корень −c/b;
  - b = 0 и c = 0 → любое x;
  - b = 0 и c ≠ 0 → корней нет.
- Иначе D = b² − 4ac:
  - `!isfinite(d)` → переполнение;
  - |D| < eps → один корень −b/(2a);
  - D < 0 → нет действительных корней;
  - D > 0 → два корня (−b ± √D)/(2a).
- `+ 0.0` превращает «минус ноль» в обычный 0 для аккуратного вывода.

### is_same_coefficients

1, если три пары чисел совпадают с точностью eps.

### solve_permutations

1. Массив `orders[6][3]` хранит все 6 порядков индексов: {0,1,2}, {0,2,1}, ….
2. Для каждого порядка собирается `current`.
3. Перестановка сравнивается со всеми уже сохранёнными; если такая была, `continue`.
4. Новая записывается в `equations[*count]` и решается. `solve_quadratic` пишет ответ прямо в поля структуры через `&equations[*count].x1`.
5. `(*count)++` — скобки нужны, чтобы увеличить значение, а не сдвинуть указатель.

### is_multiple (-m)

Оба числа ненулевые, иначе ошибка. `a % b == 0` → кратно. Случай b = −1 отдельный: на −1 делится всё, а `LONG_MIN % -1` в C вызывает переполнение и может уронить программу.

### is_right_triangle (-t)

1. Стороны < eps (не положительные) → не треугольник.
2. Самая длинная сторона ставится в c обменом через `tmp`.
3. Проверка |a² + b² − c²| < eps (теорема Пифагора).

### print_equation

Только печать уравнения и ответа по `type`. `%g` выводит число компактно.

### main

`switch (flag[1])`. Для каждого флага своя проверка `argc`: `-q` и `-t` → 6, `-m` → 4. Затем перевод чисел, проверка eps > 0, вызов функции, печать.

## Задание 4 — task4.c

Запуск: `.\task4.exe -d tests\in4.txt` или `.\task4.exe -nd tests\in4.txt tests\res.txt`.

### is_latin, is_digit, is_special

Символ — это число (код ASCII). Буквы и цифры идут подряд, поэтому проверяется диапазон: `c >= 'a' && c <= 'z'`. Стандартная `isalpha` не используется, потому что она зависит от локали. `is_special` — не буква, не цифра, не пробел и не `'\r'` (в Windows строки заканчиваются `\r\n`).

### parse_flag

1. Первый символ `-` или `/`.
2. `letter = flag + 1`. Если там `'n'`, то `has_output = 1` и `letter++`.
3. Должна остаться ровно одна буква из `d`, `i`, `s`, `a`.

### make_output_name

Создаёт `tests\out_in4.txt` из `tests\in4.txt`.
1. Цикл ищет последний `/` или `\` (`'\\'` — один символ). `name` = начало имени файла.
2. `dir_length = name - input` — вычитание указателей даёт длину пути до имени.
3. `malloc(strlen(input) + 4 + 1)`: путь + `"out_"` + `'\0'`.
4. `memcpy` (путь) → `strcpy` (`"out_"`) → `strcat` (имя).
5. Параметр `char **output`: функция меняет указатель вызывающего кода, поэтому нужен адрес указателя.

### Общий цикл чтения

```c
int c;
while ((c = fgetc(in)) != EOF) { ... }
return ferror(in) ? STATUS_READ_ERROR : STATUS_OK;
```

- `int`, а не `char`: `fgetc` возвращает 0…255 или `EOF` (−1), и в `char` их не различить.
- `ferror` отличает ошибку чтения от конца файла.

### remove_digits (-d)

`if (!is_digit(c) && fputc(c, out) == EOF)` — пишем всё, кроме цифр. `&&` ленивое: если `c` — цифра, `fputc` не вызывается.

### count_in_lines (-i, -s)

Параметр `int (*should_count)(int)` — указатель на функцию: что считать, решает `is_latin` или `is_special`. На `'\n'` записывается счётчик и обнуляется. `has_chars` нужен, чтобы записать последнюю строку, если файл не заканчивается `\n`.

### replace_with_hex (-a)

Цифры пишутся как есть, остальное через `fprintf(out, "%02X", c)`: hex заглавными, минимум 2 знака (`\n` → `0A`).

### process_file

`switch (action)` вызывает нужную функцию. `is_latin` и `is_special` передаются без скобок: передаётся сама функция.

### main

1. `argc < 3` — ошибка. Затем `parse_flag`.
2. С `n`: `argc` должен быть 4, имя копируется в `malloc`. Без `n`: `argc` 3, вызывается `make_output_name`. Копия делается всегда, чтобы в конце всегда был `free`.
3. `strcmp(вход, выход) == 0` → ошибка: `fopen(..., "w")` очистил бы входной файл.
4. `fopen` входного; при ошибке `free`. `fopen` выходного; при ошибке `fclose(in)` и `free`.
5. `process_file`, затем `fclose(in)`. Проверяется результат `fclose(out)`: данные окончательно пишутся на диск при закрытии.
6. Сообщение по статусу, `free(output_name)`.

## Задание 5 — task5.c

Запуск: `.\task5.exe <eps> <x>`, например `.\task5.exe 0.000001 0.5`.

### Типы

`Series` — функция-ряд (x, eps, result). `Function` — подынтегральная функция `double f(double)`.

### Идея рядов

Следующий член = предыдущий × отношение aₙ₊₁/aₙ. Факториалы не вычисляются: 171! переполняет `double`. Остановка, когда |член| < eps.

### sum_a — Σ xⁿ/n! = eˣ

Отношение x/n. Условие остановки дополнено `n > |x|`: до этого члены могут расти. `!isfinite(sum)` → переполнение (например, x = 1000).

### sum_b — Σ(−1)ⁿx²ⁿ/(2n)! = cos x

Отношение −x²/((2n+1)(2n+2)).

### sum_c — Σ 27ⁿ(n!)³x²ⁿ/(3n)!

Отношение 9(n+1)²x²/((3n+1)(3n+2)), сокращено из 27(n+1)³x²/((3n+1)(3n+2)(3n+3)). Предел отношения x², поэтому по признаку Даламбера ряд сходится только при |x| < 1. Проверка `fabs(x) > 1 - eps` → `STATUS_INVALID_X`.

### sum_d — Σ(−1)ⁿ(2n−1)!!x²ⁿ/(2n)!!, n от 1

Первый член −x²/2 считается до цикла, отношение −(2n+1)x²/(2n+2). Проверка остановки стоит перед вычислением следующего члена. Сходится при |x| < 1, сумма 1/√(1+x²) − 1.

### function_a … function_d

ln(1+x)/x, e^(−x²/2), −ln(1−x), xˣ. У a неопределённость 0/0 в точке 0, у c бесконечность в точке 1. Метод средних прямоугольников концы не вычисляет.

### midpoint_rule

```c
h = (b - a) / n;
for (i...) sum += f(a + h * (i + 0.5));   // значение в середине i-го отрезка
*result = sum * h;
```

Сумма площадей прямоугольников с высотой в середине каждого отрезка.

### integrate

n = 1, 2, 4, 8, … до 2²⁴. Останавливаемся, когда результаты при n и 2n отличаются меньше чем на eps.

### main

Массивы `sums[4]` и `functions[4]`. Цикл по рядам: `sums[i](x, eps, &value)`. Цикл по интегралам: `integrate(functions[i], 0, 1, eps, &value)`. `value = 0.0` перед каждым вызовом, чтобы при ошибке не печатать мусор.

## Задание 6 — task6.c

Запуск: `.\task6.exe`. Все примеры встроены в функции `demo_...`.

### Переменное число аргументов (stdarg.h)

```c
Status polynomial(double *result, const double x, const int degree, ...) {
    va_list args;
    va_start(args, degree);              // начать после последнего обычного параметра
    v = va_arg(args, double);            // взять следующий аргумент как double
    va_end(args);                        // обязательно завершить
}
```

- Функция не знает, сколько аргументов передано, поэтому количество передаётся обычным параметром.
- Вещественные аргументы нужно передавать как `1.0`, а не `1`: целое передастся как `int` и будет прочитано неправильно.
- `float` в `...` автоматически превращается в `double`.

### is_convex(result, eps, count, x1, y1, x2, y2, ...)

1. Проверка `count >= 3`. Координаты читаются в массив `malloc(2 * count * sizeof(double))`.
2. Для каждой вершины i берутся рёбра e1 = P[i+1] − P[i] и e2 = P[i+2] − P[i+1] (индексы по модулю `count`, многоугольник замкнут).
3. `cross = e1.x·e2.y − e1.y·e2.x` — векторное произведение, его знак показывает направление поворота. `dot` — скалярное.
4. |cross| < eps — точки на одной прямой: если `dot < 0` (разворот назад), многоугольник невыпуклый; иначе вершина пропускается.
5. Все знаки `cross` должны быть одинаковыми.
6. Сумма углов поворота `atan2(cross, dot)` должна быть ±2π. Это отсекает самопересекающиеся фигуры (звезда: 4π).
7. `free(points)`.

### polynomial(result, x, degree, a_n, …, a_0)

Схема Горнера: `value = value * x + коэффициент` для `degree + 1` коэффициентов, от старшего к младшему. `!isfinite` → переполнение.

### char_to_digit, parse_in_base

Символ → значение цифры: `'0'..'9'` → 0..9, `'A'..'Z'` и `'a'..'z'` → 10..35. Строка → число по схеме Горнера `value = value * base + digit` с проверкой, что цифра меньше основания, и проверкой переполнения.

### is_kaprekar

n — число Капрекара, если n² = left·baseᵏ + right, right > 0 и left + right = n (45² = 2025: 20 + 25 = 45). Перебираются power = base, base², …: `left = square / power`, `right = square % power`. n ≤ 2³² − 1, иначе n² не влезет в `unsigned long long`.

### find_kaprekar(flags, base, count, "str1", "str2", …)

Для каждой строки из `...` (`va_arg(args, const char *)`) выполняет перевод и проверку и записывает `flags[i] = 1` или `0`. Печать — отдельно в `print_kaprekar`.

### geometric_mean(result, eps, count, ...)

Числа < −eps → ошибка. Если есть ноль (|x| < eps), результат 0. Иначе exp(Σ ln xᵢ / count): через логарифмы, чтобы произведение не переполнилось.

### power_recursive — рекурсия

```c
if (n == 0) { *result = 1; return OK; }      // база рекурсии
power_recursive(base, n / 2, &half);         // рекурсивный вызов
*result = half * half;
if (n % 2 == 1) *result *= base;
```

xⁿ = (x^(n/2))², плюс множитель x при нечётном n. O(log n) умножений.

### fast_pow

Обёртка над рекурсией.
- Отрицательная степень при |base| < eps → деление на ноль.
- Модуль степени: `0U - (unsigned)exponent`, это работает и для `INT_MIN`.
- Для отрицательной степени результат 1/xⁿ. Если xⁿ переполнилось, ответ 0.

### bisection (здесь без param)

То же, что в задании 2. Тестовые уравнения: `square_minus_two`, `cos_minus_x`, `cubic`, `sine`.

### status_message, demo_..., main

`status_message` переводит статус в текст. Каждая `demo_` вызывает функции на примерах и печатает результат, включая ошибочные случаи: две точки, отрицательное число, 0⁻¹, отрезок без корня. `main` просто вызывает все `demo_`.

## Задание 9 — task9.c

### parse_int

### random_in_range

1. `range = b - a + 1` в `unsigned long long`, чтобы не было переполнения.
2. В Windows `RAND_MAX = 32767`, поэтому 4 вызова `rand()` склеиваются в одно большое число.
3. Ответ: `a + random % range`.

`srand(time(NULL))` в `main` задаёт начальное значение, иначе числа были бы одинаковыми при каждом запуске.

### swap_min_max

Один проход: запоминаем индексы минимума и максимума. Затем обмен этих элементов через `tmp`. Через параметры возвращаются сами значения min и max.

### compare_ints

Функция сравнения для `qsort`, через `const void *`, потому что `qsort` универсальная. Возвращает `(a > b) - (a < b)`, то есть −1, 0 или 1. Вариант `a - b` мог бы переполниться.

### find_closest

Бинарный поиск в отсортированном массиве: первый элемент ≥ value. Ближайший — он или предыдущий (сравниваются расстояния через `abs`). O(log m).

Итого O((n + m) log m) вместо O(n·m).

### main
